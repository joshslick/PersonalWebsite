Joshua Slick – Personal Portfolio

Overview:
This project is a personal portfolio website built using HTML, CSS, and JavaScript. It presents my professional background, technical skills, projects, and contact information in a clean, responsive vCard format.

Sections:
- Sidebar: Includes profile picture, contact info, and social links
- About Me: Brief biography and educational focus
- What I'm Doing: Highlights current skills and activities
- Resume: Education and work experience timeline
- Skills: Programming languages, tools, and hardware experience
- Portfolio: Live project links and GitHub repositories

Technologies Used:
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Ionicons
- Netlify (for deployment)
